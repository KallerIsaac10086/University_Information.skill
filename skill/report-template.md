## 3. 使用说明

- 评分结果展示放在报告最顶部，一目了然
- 各维度章节中，每个问题需标注 **得分** 和 **实际回答内容**（引用校友原话或概括）
- 总结与建议部分应结合用户给出的优先级权重，指出该校在用户最看重的方面表现如何

## 4. MD 文件产物输出

调研报告完成后，必须将完整报告写入一个 **MD 文件**作为最终产物交付：

### 文件命名规则

```
{大学拼音}-report.md
```

例如：
- 中国政法大学 → `zhong-guo-zheng-fa-da-xue-report.md`
- 北京大学 → `bei-jing-da-xue-report.md`

### 输出位置

文件放在当前工作目录下。

### 输出要求

- MD 文件内容与对话中展示的报告**完全一致**，使用 `write_to_file` 工具写入
- 写入完成后，告知用户文件路径，作为调研结束的交付物
- 这是**必须执行的步骤**，不可跳过
