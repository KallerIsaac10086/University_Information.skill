# 评分标准与计算公式

## 1. 询问用户各维度优先级

在生成报告前，先询问用户对以下 **4 个维度**的看重程度（优先级），让用户为每个维度分配权重，总和为 100%：

| 维度 | 涵盖内容 | 默认权重 |
|------|----------|----------|
| 🏠 **住宿条件** | 上床下桌、空调、独立卫浴、洗衣机、电瓶车、限电、宿舍空间 | 25% |
| 🎓 **学业氛围** | 早晚自习、晨跑、通宵自习室、大一能否带电脑、校园网质量 | 25% |
| 🎉 **生活便利** | 外卖、交通地铁、食堂价格、超市、快递、共享单车 | 25% |
| 🔓 **自由程度** | 门禁、查寝封寝、晚归处理、断电断网、热水供应时间、请假制度 | 25% |

**提问示例**：
```
在生成报告之前，请告诉我你对以下 4 个方面的看重程度（总权重 100%）：

1. 🏠 住宿条件（上床下桌、空调、独立卫浴等）
2. 🎓 学业氛围（自习条件、校园网、学习环境等）
3. 🎉 生活便利（交通、食堂、外卖、快递等）
4. 🔓 自由程度（门禁、查寝、断电等）

例如：30%、30%、20%、20%
```

如果用户不愿指定，则使用默认等权重（各 25%）。

## 2. 逐项评分标准

对每个问题按 **1-10 分**打分，10 分为最优：

| 问题 | 打分依据 |
|------|----------|
| 上床下桌 | 是=10分，否=3分，部分/分情况=6分 |
| 空调 | 有=10分，无=0分 |
| 独立卫浴 | 有=10分，公共澡堂且不远=6分，公共且远=3分 |
| 早晚自习 | 无=10分，仅大一有=7分，全有=3分 |
| 晨跑 | 无=10分，有=3分 |
| 跑步打卡 | 无或轻松=10分，中等=6分，严格=3分 |
| 寒暑假 | 正常=7分，长=10分，短=4分 |
| 外卖 | 允许且方便=10分，允许但不方便=7分，不允许=2分 |
| 交通 | 有地铁/市区=10分，郊区有公交=6分，偏远=3分 |
| 洗衣机 | 每层有=10分，楼下公共=7分，无=2分 |
| 校园网 | 快且便宜=10分，一般=6分，差=3分 |
| 断电断网 | 不断=10分，11点后断=7分，早断=4分 |
| 食堂价格 | 便宜好吃=10分，一般=6分，贵/差=3分 |
| 热水供应 | 全天=10分，时段长=7分，时段短=4分 |
| 电瓶车 | 允许且可充电=10分，允许但充电难=6分，不允许=3分 |
| 限电 | 不限或大功率=10分，有限制=6分，很严格=3分 |
| 通宵自习 | 有去处=10分，有限制=6分，无=3分 |
| 带电脑 | 允许=10分，限制=5分 |
| 消费方式 | 手机/一卡通都可=10分，仅一卡通=7分 |
| 银行卡 | 发=10分，不发=5分 |
| 超市 | 大且全=10分，小=6分，无=2分 |
| 快递 | 方便=10分，一般=6分，不便=3分 |
| 共享单车 | 多且方便=10分，有但少=6分，无=3分 |
| 门禁 | 无门禁=10分，11点后=7分，早关门=4分 |
| 查寝封寝晚归 | 不查/不封=10分，查但宽松=7分，严格=4分 |

## 3. 计算综合生存指数

```
综合生存指数 = Σ(维度得分 × 维度权重)

其中每个维度得分 = Σ(该维度下各问题得分) / 该维度问题数
```

**维度-问题归属**：

| 维度 | 包含问题 |
|------|----------|
| 🏠 住宿条件 | 上床下桌、空调、独立卫浴、洗衣机、电瓶车、限电、超市（共7项） |
| 🎓 学业氛围 | 早晚自习、晨跑、跑步打卡、通宵自习、带电脑、校园网（共6项） |
| 🎉 生活便利 | 外卖、交通、食堂价格、热水供应、消费方式、银行卡、快递、共享单车（共8项） |
| 🔓 自由程度 | 断电断网、寒暑假、门禁、查寝封寝晚归（共4项） |
