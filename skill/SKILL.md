# 大学信息获取skill

从 CNB 仓库 [Isaac80686/University_Information](https://cnb.cool/Isaac80686/University_Information) 获取中国大学的校园生活问答信息（基于 **33,579 份**真实问卷，覆盖 **5,000+** 所院校），并可生成带综合评分的大学调研报告。

> **数据来源**：[大学生活质量指北](https://colleges.chat/)（colleges.chat）社区用户匿名投稿，不代表学校官方立场，仅供参考，不构成报考或择校建议。

## 适用场景

当用户询问以下类型的问题时调用此 skill：
- 大学宿舍条件（上床下桌、独立卫浴、空调等）
- 查寝、门禁、晚归政策
- 熄灯断电、热水供应
- 食堂、外卖、校园网
- 早晚自习、晨跑、跑步打卡
- 交通、快递、共享单车
- **需要生成某大学的调研报告、综合评分**
- **需要生成精美可互动的网页展示调研数据**
- 其他校园生活质量相关问题

   - 用户确认后，重新拉取远端仓库文件覆盖本地 skill 目录
   - 更新完成后告知用户，然后继续执行用户原本请求的任务
4. 如果已是最新版本，直接继续执行任务

> 此检查仅在每次对话开始时执行一次，避免重复检查。

## 重要：使用内置工具与用户交互（必须遵守）

本 skill 全流程中的所有用户交互（**包括**：询问要调研的大学、询问权重分配、确认是否生成网页），**必须使用 agent 自带的提问工具**（如 AskUserQuestion 或等效工具）来向用户发起询问，**绝对不允许**要求用户在对话框中手动输入内容。

> 严禁行为举例（禁止）：
> - ❌ "请告诉我你想调研哪所大学？"（等待用户手动回复）
> - ❌ "请输入四个维度的权重，用逗号分隔"
> - ❌ "请手动输入你的选择"
>
> 正确做法：
> - ✅ 使用 AskUserQuestion 工具，通过 `options` 参数让用户点击选择
> - ✅ 对于权重分配，使用 AskUserQuestion 的多个问题 + 选项形式让用户选择（如"每个维度 25%"、"住宿优先"、"学业优先"等预设方案，或"自定义"让用户输入）
> - ✅ 对于大学名称，使用 AskUserQuestion 让用户输入文本

## 工作流程

### 流程 A：简单问答

当用户只问一两个具体问题时，直接读取页面后回答即可。

### 流程 B：完整调研报告

当用户要求生成调研报告或综合评分时，执行以下完整流程：

```
1. [询问学校]         → 使用 AskUserQuestion 工具询问用户要调研哪所大学
2. [询问权重]         → 使用 AskUserQuestion 工具询问用户4个维度的权重分配
                        ⚠️ 必须询问！绝对不能跳过此步骤！
                        提供预设方案供选择（如"每项25%"、"住宿优先"、"学业优先"、"生活便利优先"、"自由优先"），
                        也可提供"自定义"选项让用户设置具体权重。
3. [询问网页]         → 使用 AskUserQuestion 工具询问用户是否需要在最后生成精美可互动网页
                        ⚠️ 这一步和第1、2步一起在一开始就问完，不要留到后面才问。
                        → 参考 webpage-generator.md
4. [获取数据]         → 参考 data-fetching.md 获取全部24个问题数据
5. [计算评分]         → 参考 scoring-guide.md 逐项打分并计算综合指数
6. [生成报告]         → 参考 report-template.md 输出完整报告
7. [产出MD文件]       → 将完整调研报告写入 MD 文件（产物交付）
                        → 文件名格式：{大学拼音}-report.md
                        → 例如：zhong-guo-zheng-fa-da-xue-report.md
8. [生成网页]         → 如果用户在第3步选择了需要网页，则在此步生成
                        → 参考 webpage-generator.md 生成 HTML 文件
```
