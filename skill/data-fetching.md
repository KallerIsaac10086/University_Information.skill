# 数据获取

## 1. 确定大学名称的 URL slug

该网站使用大学中文名的拼音作为 URL 路径。格式为：
```
https://cn.colleges.chat/universities/{university-slug}/
```

常见命名规则：
- 全称拼音，用连字符 `-` 连接：如 `xi-nan-zheng-fa-da-xue`（西南政法大学）
- 注意：不要用缩写或简称，需要用完整官方校名

**如果 slug 不确定，先用通用搜索找到正确页面。**

## 2. 获取页面内容

使用 `WebFetch` 工具获取页面内容：
```
WebFetch(url="https://cn.colleges.chat/universities/{slug}/")
```

## 3. 处理内容截断问题

该网站的侧边栏非常庞大（包含全国所有已归档大学列表），可能导致正文内容被截断。

**如果正文被侧边栏淹没**，尝试以下方法：

### 方法 A：直接搜索目标问题锚点
页面中的问题有固定锚点，格式为 `#q`、`#q_1`、`#q_2` ... `#q_N`，可以跳转到具体问题：

```
WebFetch(url="https://cn.colleges.chat/universities/{slug}/#q_24")
```

### 方法 B：使用 WebSearch 辅助
如果直接获取页面内容仍不完整，可以用 WebSearch 补充搜索：
```
WebSearch(query="大学名 宿舍 查寝 site:cn.colleges.chat")
```

## 5. 信息呈现

获取到信息后，以结构化方式呈现给用户：

1. **标注信息来源**（是哪位校友/哪一年的回答）
2. **如果多个回答不一致**，分别列出不同情况（如新校区 vs 老校区）
3. **如果页面中没有相关内容**，请明确告知用户该网站没有收录该大学的信息

## 6. 已知限制

- 部分大学的页面数据可能较少（仅1-3条回答）
- 有些页面可能已被标记为"已归档"
- 数据主要来自在校生/校友的匿名投稿，不一定完全准确或最新
- 部分大学的 slug 命名可能不规律，需要尝试多个变体
- 评分仅基于公开的校友反馈，不包含官方数据
